Carpeta del curso Prioridades de Cooperación Internacional al Desarrollo.

index.html                     -> Aula virtual del curso (página principal).
herramienta-priorizacion.html  -> Herramienta de priorización (única versión; el curso abre este mismo archivo).
materiales/                    -> PDF del programa y de las presentaciones; materiales/img: imágenes de fondo.
course-content.html            -> Solo redirige a index.html (para enlaces antiguos).

Para cambiar la herramienta, edite solo herramienta-priorizacion.html: el curso queda sincronizado automáticamente.
